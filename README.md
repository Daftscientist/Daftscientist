# Hi, I'm Leo

I'm a software engineer based in England. I've been programming since I was around 12 or 13, and I enjoy working on software closer to the operating system.

A lot of my work involves understanding how software runs, how different parts communicate, and what happens when you try to run something in an environment it wasn't originally designed for.

## What I'm working on

My main public project is [domOXML](https://github.com/Daftscientist/domOXML). It's an open-source project exploring how HTML and CSS can be converted into editable PowerPoint documents.

The work involves using browser-resolved layouts and translating them into structured document content. It's still in development, and domOXML will eventually be called AftDeck.

I'm also developing Author, an application that currently handles the.aftdoc format. It isn't publicly released.
